# 第一层外排五箱的技能与预接触留距

第一层外排按 F1 至 F5 码放，物理对象依次是 `Cube_12`、`Cube_15`、`Cube_13`、`Cube_14`、`Cube_6`。+Y 朝已就位的后排，+X 朝右墙。每箱先侧吸搬到 landing，再重新观测并推到各自的后排箱。 [逐箱运行线](long_skill_short_state_routes.md#第一层前排-f1f5)

## 技能接口

**五箱都可以用 K0–K5 表达，无需新增运动技能。** 外排新增的是观察条件、技能的组合顺序以及部分进场途经点。目标可变，命令格式一致。 [六个技能的输入与输出](long_skill_short_state.md#六个技能的输入输出和结束条件)

| 外排动作 | 调用及输入 | 输出与交接条件 |
| --- | --- | --- |
| 单腕进场、两腕让出视野、导轨移位和高位下降 | K0 输入实测关节与导轨位置、TCP 目标和碰撞几何。按需给高位途经点和另一腕的状态 | 输出避障的关节轨迹，导轨移动时同时输出导轨轨迹。到达预接触位后进入 K1 |
| 前面、侧面及重新进场贴面 | K1 输入参与腕、实测 TCP、目标面及法向 | 输出低速法向关节增量。通过位置和腕力确认贴面 |
| 双杯吸附、带箱搬放和解吸 | K2 输入杯及 ON/OFF。K3 输入箱位、双杯抓持关系、landing、障碍和支撑 | K2 输出杯阀命令，K3 输出双臂及导轨同步轨迹。确认双杯连接后起吊，落稳且底部承重后关杯 |
| 进入横推区、推贴侧墙、留隙对齐、直推后排箱 | K4 输入实测箱位、参与腕、推进轴、可选保持轴，以及位置目标或承载目标 | 输出统一的关节增量。位置与腕力修正按控制方向合成。观测器按任务确认到达、承载或稳定位姿 |
| 换臂、清场前撤离、最终退出 | K5 输入需撤离的腕及法向、实测 TCP、分离阈值和允许范围 | 输出低速关节增量。单腕交接用该杯分离事件，双腕均离开且地板承重时确认 S0 |

相机重新拟合输出箱面、箱位和槽口余量，供 K0 和 K4 消费。后方承载确认输出观测事件，供 K4 切换。二者都属于观测接口。F1/F2 的相机让位由 K5 和 K0 组合，F5 的微调由已有推箱技能完成。现行外排 B 段按落地真空 OFF 推箱。旧实跑的部分后方承载判据有 PhysX 辅助，F3/F4 的仅用传感器确认后方承载属于独立验证入口。 [外排控制实现](front_row_skills.py) · [外排实跑记录](observed_skills_validation.md#f1-前排第-1-箱)

## F1 至 F5 的技能和状态

五箱的上料 A 段都执行 **K0 进场 → K1 贴面 → K2 ON → K3 起吊与搬放 → K2 OFF → K5 双腕离面**。状态依次经过 **S0 → S1 → S2 → S3 → S2 → S0**。F1、F3、F5 从左右面侧吸。F2、F4 左腕吸后面，右腕吸前面。吸附面改变目标法向及抓持变换。

| 箱位 | 从 landing 到就位 | 技能的交接观察 |
| --- | --- | --- |
| **F1** | 左腕 K0、K1 贴前面，K4 后推到横推区。右腕 K0、K1 到右面，K4 向左推贴左墙，左腕协同轻压。右腕先 K5，左腕再 K5。双腕 K0 让出相机视野，左腕根据新箱位 K0、K1 贴前面，K4 直推到 R1。左腕 K5 后 K0 归位 | 横推区由后排箱面确定。确认左墙承载后依次分离，第一腕离开时仍为 S1。两腕离开确认 S0，再清场并重新拟合。第二次进场回到 S1。确认 R1 承载和箱位稳定，末段撤回 S0 |
| **F2** | 右腕 K0、K1 贴前面，K4 后推到横推区。左腕 K0、K1 到左面，K4 向右推贴右墙，右腕协同轻压。左腕先 K5，右腕再 K5。双腕 K0 让出视野，右腕重新 K0、K1，K4 直推到 R2。右腕 K5 后 K0 归位 | 顺序与 F1 对称。确认右墙承载后依次分离，先确认单杯撤离，再确认 S0。最终要求 R2 承载及箱位稳定 |
| **F3** | 右腕 K0、K1 贴右面，K4 向左与 F1 对齐并留侧隙。右腕 K5 后 K0 清场。左腕 K0、K1 贴前面，K4 沿 +Y 直推到 R3。左腕 K5 后 K0 归位 | 横推以箱位和朝向为目标，观测器以右杯分离作为换臂条件。重新拟合，检查侧隙和偏航后，才直推至 R3 承载。最终确认 S0 |
| **F4** | 左腕 K0 从上方对准再下降，K1 贴左面，K4 向右与 F2 对齐并留侧隙。左腕 K5 后 K0 清场。右腕 K0 从上方对准再下降，K1 贴前面，K4 沿 +Y 直推到 R4。右腕 K5 后 K0 归位 | 左杯分离才换臂。重新拟合侧隙及偏航，确认可直推。最终核对 R4 承载和箱位稳定，再确认 S0 |
| **F5** | D455 拟合 F3 与 F4 间槽口及当前箱位。槽口可通时，左腕 K0、K1 贴前面，K4 直推至 R5，再 K5、K0。若需向左微调且满足既有条件，先由右腕 K0、K1 贴右面、K4 向左小推，K5 分离后 K0 清场，重测槽隙 | 左右投影余量都为正才走常规直推。微调的目标由两侧余量差得到，完成后仍须重测两侧。已验收的标准路线为直接推入，末段确认 R5 承载及稳定后退回 S0 |

F1/F2 的 B 段有一次明确的中途 S0，由先撤侧推腕、后撤前腕触发。F3/F4 在横向对齐后先确认当前工作的腕已离面，再进入另一腕的独立进场。若两腕均已离开且箱底受托，状态也为 S0。F5 直推路线只有一次接触循环。所有 B 段的有接触推送都属于 S1，地板承担箱重。

## 7 mm 留距核验

7 mm 指 K0 终点到目标箱面的法向留距。F1 侧腕历史上从 30 mm 的外侧用高位下降，再到名义 7 mm 开始低速贴面。F2 侧腕高位下降已使用 7 mm。F3 采用直接进场，F4 保留从上方对准再下降。F5 常规验证从箱前进入，槽口两侧拟合余量曾为 0.933 和 0.041 mm，属于箱体通行条件。历史 F1/F2 在最后一小段开启进场杯接触许可。本轮把许可移到了实测到位之后，并对照整段 PhysX 原始接触记录。 [历史外排运行记录](observed_skills_validation.md#f1-前排第-1-箱)

从各箱实测 landing 或换臂断点恢复，以单个 Isaac Sim 4.5 实例逐个完成标准路线的进场试验。F3 右腕在原运行已完成且记录完整，左腕从该次运行第 7,550 个物理步、箱子已横向对齐且两杯已离开的断点恢复。首次恢复仍在对齐前的 landing 区域找箱，D455 未返回稳定拟合。复验用断点记录的上一次 D455 拟合作为搜索初值，等新帧重新确认箱位后才规划。

| 箱位 | 进场顺序 | K0 末端实测法向间隙 | K0 提前触箱／冲量帧 | K1 贴面确认 |
| --- | --- | --- | --- | --- |
| F1 | 左腕前面 → 右腕右侧 → 左腕重新进场 | 6.34 / 7.12 / 6.06 mm | 0 / 0 | 3/3 |
| F2 | 右腕前面 → 左腕左侧 → 右腕重新进场 | 7.12 / 7.50 / 5.64 mm | 0 / 0 | 3/3 |
| F3 | 右腕右侧 → 换臂后左腕前面 | 7.70 / 5.68 mm | 0 / 0 | 2/2 |
| F4 | 左腕左侧 → 换臂后右腕前面 | 7.18 / 6.20 mm | 0 / 0 | 2/2 |
| F5 | 左腕前面，常规直推路线 | 7.09 mm | 0 / 0 | 1/1 |

11 次均按名义 **7 mm** 生成目标，实测间隙为 **5.64–7.70 mm**。检查了 23,730 个进场物理帧，进场杯提前触箱和原始冲量均为零。K1 均由腕力确认贴面，PhysX 同步记录相应吸盘承载。间隙是 TCP 到实际箱面的法向距离。

F1、F2 侧腕先从上方进场，再到 7 mm 预接触位。F1、F2 的侧腕末段与正面姿态对准，以及 F4 的换臂后下降，另用实测双臂关节回放复核了 2 mm 模型余量。运行器在实测到位后才开放该杯接触许可。F4 换臂后的末段下降也增加同一实测到位检查。F1 的外侧高位途经点服务于绕障，K1 的交接目标仍是 7 mm。F5 的可选侧向微调未进入这组标准路线，箱体槽口两侧间隙仍独立检查。试验到最后一次 K1 贴面确认结束。 [本轮逐次数据](validation/observed/front_row_k0_7mm_20261127.json) · [历史供料与 B 段基准](validation/observed/front_row_k0_baseline.json)

## 复现

在仓库根目录运行，每次使用新输出目录。F1、F2 可替换成各自的 landing 断点。

```bash
obs=scenes/w760_300mm_two_layer/validation/observed
sim=/home/ubuntu2004/isaacsim-4.5.0
"$sim/python.sh" "$obs/front_row_k0_probe.py" /tmp/fr3-front2-k0-7mm \
  --observed-skills --resume "$obs/front2_landing_checkpoint.json" --headless --close-on-finish
"$sim/python.sh" "$obs/front3_aligned_k0_probe.py" /tmp/fr3-front3-k0-resume \
  --observed-skills --resume "$obs/front3_aligned_k0_checkpoint.json" --headless --close-on-finish
```
