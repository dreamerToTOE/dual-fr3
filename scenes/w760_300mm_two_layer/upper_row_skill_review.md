# 第二层第一排五箱的技能复用与 7 mm 进场

U1 至 U5 分别对应 `Cube_7` 至 `Cube_11`，码好后从左到右为 U1、U3、U5、U4、U2。第一层两排托住上层箱，+Y 朝后墙，+X 朝右墙。五箱均从相对的两个竖直面侧吸上料。 [上层逐箱运行线](long_skill_short_state_routes.md#第二层靠后墙一排-u1u5)

## 技能接口

**跨缝、换臂和最终进槽都可复用 K0–K5。** 跨缝是同一对吸盘带箱的短程搬放，换臂由单腕分离后的观察事件衔接，进槽是一腕推着由下层托住的箱。变化的是参与腕、路径约束和完成条件。 [技能的输入输出与结束条件](long_skill_short_state.md#六个技能的输入输出和结束条件)

| 技能 | 上层输入 | 输出与交接 |
| --- | --- | --- |
| K0 空载避障 | 实测关节、导轨和 TCP，实时箱面生成的预接触位或清场目标，按需增加高位途经点、碰撞几何和另一腕状态 | 输出空载关节轨迹，必要时含导轨轨迹。确认预接触到位后才进入 K1 |
| K1 低速贴面 | 指定腕、实测 TCP、目标面及法向、进给范围和力反馈 | 输出低速法向关节增量。由腕力和 TCP 运动确认贴面。跨缝落稳后可按当前姿态短程复贴 |
| K2 吸盘开关 | 目标杯及 ON/OFF | 输出杯阀命令。双杯吸附确认后进入 K3。下层承重稳定后断开吸附 |
| K3 双腕带载搬放 | 实测箱位和双腕状态、共享抓持关系、支撑与障碍、landing 或接缝另一侧的落点 | 输出双腕同步关节轨迹，按需含导轨。跨缝可增加抬高、横移和低速落箱的约束。箱底在目标支撑上承重后交给 K2。当前实现用紧协调的笛卡尔/逆解轨迹 |
| K4 受支箱体推送 | 箱位、参与腕和 TCP、下层支撑、推进/稳箱方向和箱位或承载目标 | 输出统一的关节增量。位置和力修正按控制方向合成，可由一腕推，或另一腕边稳箱边跟随。按任务确认对齐、贴靠或到位稳定 |
| K5 低速离面 | 要退出的腕及法向、实测 TCP、分离阈值和允许范围 | 输出低速关节增量。对单腕确认该杯离面，对双杯确认均已离面。后续空载清场复用 K0 |

相机拟合给出箱面、落点、接缝和槽口几何。腕力与编码器确认贴面、交载和离面。看到哪一侧承载决定 K4 的下一步动作。状态与技能衔接采用同一个接口，部分历史数据含 PhysX 支撑复核，证据见逐箱记录。 [上层实跑记录](observed_skills_validation.md#u1-上层第-1-箱)

## U1 至 U5 的技能和状态

五箱上料执行 **K0 进场 → K1 贴面 → K2 ON → K3 带箱到 landing → K2 OFF → K5 双腕离面**。典型条件依次为 **S0 → S1 → S2 → S3 → S2 → S0**。到 landing 后重新拟合箱位再规划。

| 箱位 | 从 landing 到就位 | 决定交接的观测 |
| --- | --- | --- |
| **U1** | 左腕 K0、K1 贴前面，K4 先贴后墙。右腕 K0、K1 到右面。双杯 K2 ON、K3 向左跨缝、K2 OFF。K1 复贴、左腕 K4 恢复后墙承载，右腕 K4 向左推贴左墙。两腕 K5、K0 | 确认下层接稳跨缝落箱后才断吸。再确认后墙、左墙承载和箱位稳定，双腕离面后确认 S0 |
| **U2** | 右腕 K0、K1 贴前面，K4 先贴后墙。左腕 K0、K1 到左面。每次先用 K4 把箱推到跨缝入口，再用 **K2 ON → K3 → K2 OFF** 向右搬过接缝。两次落稳后都复贴并恢复后墙承载。第二次落稳后，左腕先局部让开，再调整高度及杯面俯仰，K1 复贴后 K4 推贴右墙。双腕 K5、K0 | 两次分别确认吸附、下层交载及后墙恢复。最后的侧杯高度在箱心以下 18 mm，俯仰对齐后才贴面。确认右墙承载及稳定后再双腕撤离 |
| **U3** | 左腕 K0、K1 贴前面，K4 先贴后墙。右腕 K0、K1 到右面，两腕用 **K2 ON → K3 → K2 OFF** 向左跨一道缝。落稳后复贴并恢复后墙承载，右腕 K4 向左贴 U1。双腕 K5、K0 | 末段由腕力增量、编码器停滞和当前箱面几何判断贴靠 U1。实际承载可在指令走满前产生。两腕离面且下层承重时确认 S0 |
| **U4** | 右腕 K0、K1 贴前面稳箱，左腕 K0、K1 到左面。两腕用 **K2 ON → K3 → K2 OFF** 向右跨一道缝，落稳后复贴，左腕 K4 向右贴 U2。左腕单独 K5 后 K0 清场，右腕在前面以 K1 复核贴面，再 K4 沿 +Y 推至后墙。右腕 K5、K0 | 先确认贴靠 U2，再确认左杯离面和左腕清场。右杯仍接触时保持 S1。待后墙承载、箱位稳定且右杯离面后确认 S0 |
| **U5** | 用 D455 拟合 U3、U4 之间的槽口及当前箱位。左腕 K0、K1 贴前面，K4 沿 +Y 直推到底。左腕 K5、K0 | 进槽前检查左右投影余隙和偏航。后墙承载且箱位稳定后，确认左杯离面和下层承重 |

跨缝把 **S1（受支推压）→ S2（受支吸持）→ S3（侧吸悬持）→ S2（落稳仍吸持）** 串起来。解吸后重新贴面再回到 S1。过渡中能否报 S0 用两杯离面加箱底承重判断。U4 换臂时用左杯离面作清场条件，右杯从箱旁用同一 K1 接近接口确认前面接触。 [跨缝与复贴](upper_row_push_body.txt) · [观测入口](two_row_physx.py) · [U4 右杯复贴](upper_slot4_front_seal.py) · [按观测撤离](dynamic_withdraw.py)

历史断点实跑已验证这两项组合。U4 跨缝落稳后下层连续承载 60 帧。换臂试验中，确认贴 U2 后，左腕外撤 3.84 mm 确认离面并以避障轨迹清场。右腕独自后推约 65.3 mm，左杯冲量为零，最后右腕离面进入 S0。跨缝和供料落箱共用 K3 的带载输入输出，底层采用各自的笛卡尔走廊和同步逆解。 [U4 历史跨缝和换臂证据](validation/observed/upper4_progress.json)

## 7 mm 进场核验范围

从第一层两排已就位的断点执行上层五箱的结果、恢复点和逐帧证据见 [统一 7 mm 全流程试验](upper_row_continuous_7mm.md)。

名义 7 mm 指首次或断点恢复后 K0 的终点沿目标面法向向外留出的距离。K1 随后低速贴面。夹在 K0 里的高位对准和下降服务于绕障。遇到失败先检查逆解构型、途中碰撞和高位途经点，按统一留距重试。

同一跨缝循环内的两腕复贴从箱旁的实测 TCP 开始。每次落箱后，已有的慢速法向复贴行程上限为 6 mm。U2 第二次跨缝后的侧杯另先外移 4 mm，再调整接触高度和俯仰。局部无载姿态调整和低速复贴可按 K0/K1 的接口组合表达，现行轨迹由局部笛卡尔动作实现。若使用断点从空载位重新进场，需核验该次 K0 的 7 mm。U5 左右缝隙是箱体通行条件，单独从拟合后的侧箱投影计算。 [上层历史运行与断点](observed_skills_validation.md#u1-上层第-1-箱) · [复贴轨迹实现](upper_row_push_body.txt)

供料 A 段已有五箱的历史记录。双腕先在线规划到 35 mm 预备位，末段沿箱面法向到名义 7 mm。回放历史日志的十个终点为 7.144–7.149 mm，11,561 个进场物理步无提前触箱，两杯均在随后成功吸附。当前入口已增加逐腕到位检查。本轮的新试验从 landing 断点开始，验证 B 段的 K0 到 K1 交接。

### 2026-11-27 单实例实跑

从各箱的实测 landing 断点串行启动 Isaac Sim，保留当时已码好的箱体。前面走在线 RRTConnect。侧面先在线规划到上方，再用同一肘部构型连续下降，并复核实测 TCP 到位。所有接近的终点都由箱面和 **7 mm 法向留距**生成。等移动杯达到预接触位后，才开放该杯的接触许可并开始 K1。

| 箱位 | 前面进场实测间隙 | 侧面进场实测间隙 | K0 提前触箱 / 冲量帧 | K1 腕力与 PhysX 确认 |
| --- | ---: | ---: | ---: | --- |
| U1 | 左腕 7.54 mm | 右腕 6.65 mm | 0 / 0 | 2/2 |
| U2 | 右腕 7.50 mm | 左腕 7.56 mm | 0 / 0 | 2/2 |
| U3 | 左腕 7.10 mm | 右腕 6.83 mm | 0 / 0 | 2/2 |
| U4 | 右腕 6.65 mm | 左腕 6.89 mm | 0 / 0 | 2/2 |
| U5 | 左腕 6.80 mm | — | 0 / 0 | 1/1 |

9 次标准进场均通过。逐帧核对了 16,798 个 PhysX 步，K0 无提前触箱，也无非预期接触。K1 的 9 次腕力确认都在同一步观察到对应杯对箱体传力。实测间隙以编码器 TCP 和独立 PhysX 箱面计算，包含箱面拟合与轨迹跟踪误差。在线规划累计检查 6,652 个关节路径样本，另外检查导轨运动并逐步检查侧腕的笛卡尔下降。 [逐段实跑数据](validation/observed/upper_row_k0_7mm_20261127.json)

U1 历史试验在侧腕下降时出现了肘部逆解跳支。本轮按实时箱面和 7 mm 求解，保留经验证的肘部构型作为侧腕逆解初值，下降后通过构型检查。U3 将历史 5 mm 的侧面留距改成 7 mm，仍先完成俯仰对准，再进入 K1。

U4 前面及侧面实测关节回放通过 2 mm 模型余量复核，两段的最小模型间隙分别为 6.57、6.83 mm。U5 左腕正面进场最小模型间隙为 6.74 mm。U5 的 D455 左右槽隙分别为 2.86、3.40 mm，直推入口的两侧通行检查通过。这组新试验完成到末次 K1，跨缝、换臂及 U5 直推就位的证据沿用上面所列的断点实跑。

五箱里真正最紧的是 U3 的右腕侧面下降。最接近的一对是右工具竖直外壳和 U2 箱体。按断点恢复的邻箱几何回放，最小模型间隙为 2.57 mm。按 D455 拟合的障碍位置回放，最小间隙为 2.03 mm，达到本轮采用的 2 mm 检查门槛。

U2 从跨完第二道缝的断点补测通过。右腕前面和左腕低位侧面的指令均为 7 mm，实际间隙为 8.41 和 7.28 mm，均无提前触箱，K1 均确认贴面。前面间隙多出的 1.41 mm 来自约 1.08 mm 的箱面拟合偏差及约 0.33 mm 的法向跟踪偏差。左腕在箱心下 18 mm 的接触高度完成姿态对准和贴面。 [U2 第二次跨缝断点](validation/observed/upper2_after_seam2_checkpoint.json)
