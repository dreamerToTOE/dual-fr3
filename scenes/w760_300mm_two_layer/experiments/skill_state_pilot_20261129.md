# 新技能状态的首轮双线对照

本页保留首轮全程回放记录。现行状态识别率使用[技能间空档的评分结果](skill_idle_u5_20261129.md)。

场景使用后置 D455 箱面拟合和双臂侧吸。主回放使用旧版 `SevenObserver(revised=True)`、旧 TCP 指令恢复和旧延迟补偿，并固定源码版本为 `f35b3d2`。回用的仅是算法。实验窗口、首次触发和状态标签使用新技能体系。 [实验方案](long_skill_observer_plan.md)

## 两条记录线

- **PhysX 真值线。** 使用箱体原生附着和当步接触冲量。S0 表示有支撑、两杯脱附且原生碰撞对显示与工具分离。S1 表示受支撑且杯面接触。S2 表示受支撑且至少一杯仍有原生连接。S3 表示仍有原生连接且箱底离支。底面和每个指定墙、同层邻箱分开评估。复验新增法向冲量的世界坐标分量。旧记录以标量冲量和上下层对象区分承载。
- **传感器线。** 使用带曝光和接收时刻的 D455 位姿、编码器 TCP 和重力补偿后的腕力，另用实际下发的关节目标重建 TCP 命令。迟到的视觉帧按接收时间入队，再从曝光时刻开始按旧算法根据持续传力的末端位移补偿。沿用旧方案的四种模式 `vision_fk`、`wrench_fk`、`fusion_arrival`、`fusion_compensated`。腕力对照只运行一次，含视觉的三种在同一物理记录上分别额外延迟 0、100、200 ms。所有模式使用编码器。

主比较沿用旧方案 5 mm 分离参数。适配新 K5 的融合结果用 3 mm 单列。旧原始 S1/S5/S6 的推压归为新 S1，旧 S4 悬持归为新 S3。旧 S3 交载只有在观察器也推断出有效侧吸时归入新 S2，证据不足为待确认。新 S0 和 S2 继续沿用观测器相应输出。

## 评分范围

同一物理步配对视觉和编码器观测、腕力命令记录与独立真值。观测器在每只箱的开头重置。状态表按有效真值步计数，待确认计入识别率分母。接触目标出现的 PhysX 时间与观测器首次稳定触发对照，贴靠的连续触发检查为三步，离面为六步。窗口以已执行动作的起止记录为边界。K5 的 PhysX 真值由碰撞对生命周期确定，杯面几何净距的独立真值留待单独采集。相机年龄只统计旧算法允许使用的 0–400 ms 观测，缺帧和过期另计。

整条轨迹仍由原运行器执行。观测器在旁路回放，各条件共享同一物理记录。拟合使用场景的供料和支撑面搜索范围，飞行时视觉可缺失。试验指标描述这些记录窗内的行为。正式独立集的分组、闭环和置信区间另按实验方案完成。

## 首轮结果

从整线验收日志取 U4 跨缝后到就位、U5 完整 A+B，共 51,383 个对齐物理步。另用单个 Isaac Sim 实例从该次 U5 落箱实测断点运行直推与撤离，共 13,372 步。复验稳定就位，后墙 30/30 步承载，下层 60/60 步承载，箱心偏差 1.58 mm，非预期机械臂接触为零。 [原回放结果](results/skill_state_u4_u5_20261129.json) · [U5 复验回放结果](results/skill_state_u5_repeat_20261129.json)

无额外延迟、旧 5 mm 分离参数下的逐步识别结果如下。每个单模态对照都使用编码器。

| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| U4 跨缝后 | 60.64% | 49.10% | 68.20% | 71.11% | 67.17% | — | — |
| U5 完整 A+B | 30.59% | 58.79% | 91.18% | 80.93% | 96.22% | 97.44% | 100.00% |

U5 完整 A+B 的 S2 有 156 个有效真值步，融合命中 152 步，触发正确率为 71.70%。U4 和 U5 落箱后复验的记录窗没有 S2、S3 有效样本。

旧融合额外追加 200 ms 后，三段整体识别率分别为 68.06%、91.12%、90.66%。在此次覆盖的场景中，基于到达的融合和曝光时刻补偿融合在 0、100、200 ms 各自得到相同的状态混淆计数和事件触发步。与视觉和腕力对照的差异来自多源融合；本轮暂未观察到时间补偿对状态结果的增益。

## 复现

在分支工作树根目录运行。程序从本地 Git 历史提取固定旧版本的运行模块。单分支克隆可先执行 `git fetch origin innovation-2-state-fusion` 获取该版本。Lula 仅用于重算已下发的 TCP 指令，回放不会启动 Isaac Sim。

```bash
python3 scenes/w760_300mm_two_layer/experiments/replay_skill_states.py \
  ../runs/dynamic-full-15-20261128/upper4-bearing /tmp/skill-state-u4-u5.json \
  --cube 10 11 --isaac-sim-dir /home/ubuntu2004/isaacsim-4.5.0
```

复验从上一次 U5 落箱后的实测断点启动，仍由单实例执行。

```bash
/home/ubuntu2004/isaacsim-4.5.0/python.sh \
  scenes/w760_300mm_two_layer/markerless_rows.py /tmp/skill-state-u5-landing \
  --resume ../runs/dynamic-full-15-20261128/upper4-bearing/upper_landing_checkpoint.json \
  --observed-skills --headless --close-on-finish

python3 scenes/w760_300mm_two_layer/experiments/replay_skill_states.py \
  /tmp/skill-state-u5-landing /tmp/skill-state-u5-repeat.json \
  --cube 11 --isaac-sim-dir /home/ubuntu2004/isaacsim-4.5.0
```
