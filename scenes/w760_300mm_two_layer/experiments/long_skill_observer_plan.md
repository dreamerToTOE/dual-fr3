# 长时序技能与短时序状态观测实验方案

[旧融合方案的首轮双线对照](skill_state_pilot_20261129.md)

使用 760 mm 托盘、300 mm 高墙、D455 无标记箱面拟合、双 FR3 侧吸和 K0–K5 运行器。本轮 15 箱从空托盘起经实测断点恢复，最终全部稳定就位。实验的判断单位是一次技能交接。只要当前技能在避障许可范围内正确确认了所需状态或事件，就可以从实测姿态交给下一技能。 [15 箱验收记录](../dynamic_full_15_20261128.md) · [K0–K5 和 S0–S3 定义](../long_skill_short_state.md)

## 评估哪些交接

| 交接情形 | 应确认的事件 | 独立 PhysX 参考 |
| --- | --- | --- |
| K1 贴面后开始 K2 或 K4 | 指定腕已贴到指定面，箱底受托，形成 S1 | 指定杯和目标箱的当前接触、底部支撑 |
| K2 开启侧吸 | 所需吸盘已建立有效连接，箱底仍受托时为 S2 | 仿真有效吸附关系、实际承重对象 |
| K3 起吊和落箱 | 起吊后为 S3。到达 landing 或跨缝落下后，目标支撑承重且箱体稳定，可解吸 | 有效吸附、箱体位姿和速度、源与目标支撑的竖向接触冲量 |
| K2 解吸后 K5 退出 | 指定吸盘解吸并离面。两杯均分离且箱底受托时确认 S0 | 附着解除、杯到箱面净距、接触消失和支撑 |
| U4 横推到 U2 后换臂 | U2 实际承载，左杯离面后可由右臂后推。右杯仍贴面时只发左杯离面事件 | U2 侧向承载、左杯净距和当前接触、下层承重 |
| K4 抵住指定墙或邻箱 | 指定对象实际承载。若是最后一推，还要确认箱体到位稳定，随后撤杯 | 与指定对象的当步接触冲量、箱位和速度、下层承重 |

状态输出使用 S0–S3，并单独输出工具、承托面和水平承载对象。沿用旧试验的 S0、S1 和 S2 物理条件时须按新版重标。旧六类 S4 的悬持对应新 S3，旧 S5 的受支撑推压归入新 S1，并保留各对象的承载事件。旧 S3 的交载须依据当时的支撑和吸附重新标注。日志使用单独的版本字段，既有六类分数保留原口径。 [旧创新点二的六类定义](https://github.com/dreamerToTOE/dual-fr3/blob/f35b3d257eed29aa7419ace6cc7011ebd0baee44/scenes/w760_300mm_two_layer/contact_states.md)

## 观测器和真值

传感器侧用 D455 的箱位、箱面和置信度，用关节与导轨编码器计算 TCP 位姿及其运动，并把左右腕的六维力矩换算到 TCP 后转到同一坐标系做重力补偿。视觉在曝光时刻与机器人历史对应，到达时才进入观测器。高速腕力与编码器连续更新，视觉低置信或遮挡时保留证据不足的输出。力与推进方向相投影，结合实测运动和相对几何，区分滑动阻力、贴靠后受阻以及正常卸载。

阀命令和可读执行回执用于确定操作时序。若吸盘没有可独立测得的密封信号，空载静止时保持待确认，在正常起吊和交载动作中用箱体随动与竖向载荷核验连接效果。仿真吸附标志只进入真值流。

真值使用独立的 PhysX 日志，按物理步保存接触对象、当前步冲量和法向方向、箱体位姿和速度、吸附及杯面几何净距。把底面支撑、侧邻箱和墙分别记录。接触历史过期或报告缺失时标记无有效真值。几何贴近与实际承载分别标注。本轮已有的密集状态字段使用旧口径，事件标签从原始参考记录重建。正式采集补齐各轴冲量分量和连续 RGB-D 帧。

本轮运行器在交载、部分推送和最终就位验收仍直接读取 PhysX。第一轮让观测器旁路输出，只用独立真值评分。进入闭环时只切换本轮试验所选的交接事件，并逐项排除该事件旁边的真值门槛或真值派生提示。原有轨迹避障和非预期碰撞监测参与各组。报告注明哪些交接已闭环，哪些环节仍由现有控制器执行。

## 对照、采集与冻结

1. **先核对事件标注。** 用本轮可追溯的日志复核 A 段吸附与交载、U4 换臂、U5 入槽和最终离面。用吸附失败、只有滑动阻力和未贴到指定对象构成负例。对视觉缺失的样本仍按物理事实标注。U4 左杯分离与最终两杯分离分别计数，分离确认后结束评分。此批日志用于开发与复核。
2. **三组旁路对照。** 在同一物理记录上配对回放，主对照为仅 D455、仅腕力、D455 与腕力及编码器融合。三组共用窗口开闭、任务目标、标定和阀命令，上一个物理判定与技能结束信号不作输入。再以视觉加编码器、腕力加编码器配对复算，检验两种模态各自带来的贡献。纯视觉组从原图按因果时序拟合，只使用标定与视觉历史。若复用含机器人位姿提示的拟合结果，在表中标记共同先验。
3. **设置独立测试。** 以一次实际生成的物理运行或初始条件为分组。来自同一断点的派生记录、同一轨迹的不同降质版本归到一组。正常任务覆盖三排典型箱位，用独立初始位姿同时收集正常与偏差对照。优先覆盖上料接近、落箱交载、上层跨缝、U4 换臂和 U5 直推。初轮每个关键窗口至少 3 次开发复验与 6 个独立测试运行，其中安排有真实交接和无真实交接的对照。测试开始前冻结代码、阈值、数据清单、评分规则和随机种子。后续根据置信区间宽度安排独立复验。
4. **视觉异常用成对对照。** 保留正常帧，按物理时间分别施加数据传输延迟、短时遮挡或丢帧、运动模糊。延迟和丢帧在队列到达端注入，比较固定延迟和带抖动延迟。在原始连续帧上按曝光窗口合成运动模糊，再运行同一个拟合器。测得的帧年龄、检出率和位姿误差随结果记录。现有位姿日志可以做延迟和丢帧的开发复核，像素级模糊另行采集。
5. **闭环复验。** 首批切换 A 段双杯分离、U4 单腕离面、U5 后墙承载三个交接。每次从独立物理初始条件或记录的断点启动，按同一场景和扰动配对比较现有基线与融合闭环。正确事件发出后从当时实测关节、导轨与箱位规划下一技能。随后扩展到起吊和交载，验收稳定就位、无非预期碰撞以及观测和状态交接一致。

## 评分

窗口从技能开始允许确认该事件时开启，到本次动作实际可用的避障行程或技能许可范围用尽时结束。分离行程从当前实测姿态和周围障碍计算。首次有效的真值事件定义正确触发的最早时刻，窗口内正确触发记一次命中。提前、错对象或错状态触发记误触发。有效真值出现但一直待确认或逾窗记漏检。没有目标事件的窗口用于计算误触发率。

每个状态和事件报告样本数、窗口内识别率（召回率）、触发正确率（精确率）、F1、误触发率，以及命中样本相对 PhysX 真值的延迟中位数和 P95。用物理运行分组自助抽样估计 95% 置信区间，三组差值使用同一批分组样本做配对抽样。延迟供诊断，正确性按允许窗口评分。闭环另报稳定就位率、非预期碰撞率及失败出现的技能和状态。
