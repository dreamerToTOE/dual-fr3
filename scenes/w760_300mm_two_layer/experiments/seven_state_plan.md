# 七种接触状态的同轨迹对照计划

以一次双臂运动为配对单位。按 120 Hz 物理步对比两条线的当前判断。状态采用[七种接触状态的定义](../contact_states.md)。任务控制器沿用原动作，识别结果先旁路记录。

1. **独立真值。** 审计当前步的 PhysX 对象、实际吸附、承托冲量与箱体运动。区分底部托箱与同层侧靠，记录所有同时承载的对象。补记竖直冲量用于起落交载。缺少独立物理证据的时刻标作待确认，单独报告其比例。
2. **传感器估计。** 使用独立 D455/ArUco、双腕 TCP 六维力和编码器运动学。输出主状态、水平接触对象和可观测性。按已收到的观测处理各步，保留拍摄、接收和判断时间。状态编号、控制阶段、支撑平面投影结果及物理真值不作为特征。
3. **三段配对。** 选择 A 的起吊与落箱、上层第 5 箱直推与撤腕、上层第 4 箱由侧贴邻箱转向后墙。先回放既有日志，确实缺失信号时用一个仿真实例从最近可用断点补采。缺类与运行问题逐项记录。
4. **消融。** 同一段分别运行视觉＋运动学、腕力＋运动学、按到达使用两类信号、按曝光补偿的融合。在原始接收时间上额外加入 0、100、200 ms；用独立的模糊观测作成对对照。中途失联时停止用工具位移传播箱体。
5. **验收。** 给出三段的真值与估计时间线、七类召回与混淆矩阵、待确认比例、目标提前确认次数及物理切换后的检测时间。报告独立运行数。首轮使用可解释判据。若后续训练模型，按完整运行隔离训练与测试。

结果和遇到的问题记录在本分支。指标以实际采样片段和可标注范围为准。

第一项补记用于 Isaac Sim 真值线。记录底部接触中沿世界 Z 轴的法向冲量分量幅值，结合接触对象在箱底的位置、原生侧吸约束及实际箱体运动，标注起吊和落箱时的交载。视觉时间补偿用于第二条线，依据已经收到的图像和运动学推算当前时刻。

本实验的视觉通道模拟实物相机可取得的数据。后方 D455 的 RGB 像素给出 ArUco 角点，已知码尺寸、相机内外参和码到箱体的固定偏移用于估计箱体位姿。相机标定量在仿真中给定；只取原始图像估计，保留曝光和接收时间及漏检。静置邻箱的已观测布局单列为先验。两条线只在评分时配对。研究范围为仿真内识别。
