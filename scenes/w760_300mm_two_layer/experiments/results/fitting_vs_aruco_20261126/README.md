# 双层码垛场景的视觉拟合与 ArUco 状态识别对照

测试沿用 76 cm 托盘、30 cm 高墙和 15 cm 箱体。拟合法使用已发布的场景，由同一台后置 D455 读取 RGB-D。ArUco 使用该相机的 RGB 图像估计箱位。两组回放都使用各试次记录的双腕 TCP 力/力矩、编码器、实际发出的推进指令以及当时已取得的邻箱观测。[视觉拟合法基线](https://github.com/dreamerToTOE/dual-fr3/tree/727c5ae8b9dbc9800c0f0c173fc7307e2c2b0952/scenes/w760_300mm_two_layer)

## 评分口径

- 主表复用 `SevenObserver` 的 `fusion_compensated` 修订版和 5 mm 分离阈值。第 4 箱从侧推到最终撤离开始另用原有 `U4ContactObserver` 统计 S5/S6。
- PhysX 当前接触冲量、方向分量、吸附记录和物理位姿产生 S0–S6 真值。新采集沿用创新点二的方向冲量日志。相机的曝光和到达时间、实际腕力和指令进入回放，任务阶段只用于切分评分窗口。
- 各状态识别率（召回率，Recall）以该状态的全部有效真值步为分母。整体准确率以全部有效真值步为分母。两者均计入输出“待确认”的步。真值待判定的步另计。精确率以判成该状态且真值有效的步为分母。
- A 段从上层第 1 箱上料到放稳、开杯和空臂回停。第 4、5 箱均从实测断点开始，评分截至该箱就位。各方案按单个 Isaac Sim 逐段采集或回放。

## 各状态识别率

下表按通用融合观察器汇总主比较的三个试次。

| 状态 | ArUco | 视觉拟合法 |
| --- | ---: | ---: |
| S0 工具分离 | 67.7%（14139/20897） | 80.2%（15788/19679） |
| S1 受支撑推压 | 77.5%（9023/11643） | 87.8%（15462/17602） |
| S2 侧吸且底部承重 | 88.8%（103/116） | 98.6%（73/74） |
| S3 箱重交接 | 84.7%（50/59） | 79.6%（43/54） |
| S4 悬空侧吸 | 100.0%（9331/9331） | 100.0%（9331/9331） |
| S5 单面承载 | 5.1%（186/3619） | 1.4%（69/4848） |
| S6 双面承载 | 64.5%（89/138） | 82.6%（100/121） |

A 段最终开杯前，S0 识别率从 26.8%（1000/3725）升至 68.4%（2635/3854）。最终开杯后，两版分别为 97.7% 和 98.4%。

S1 的总体识别率提高。A 段刚接触料台箱体时，S1 从 33.4% 降至 2.9%。拟合法这段 362 个 S1 漏检步中，301 步的两只吸盘均超过观察器的载荷门限，未满足单臂推压条件。S2 的识别率提高，精确率则从 95.4% 降至 51.4%。拟合法试次的 S2 和 S3 真值分别只有 74 和 54 步。

两次均从第 4 箱跨缝落稳的同一个断点启动。拟合法实跑完成横推、贴后墙和撤离，PhysX 确认就位稳定。下表使用第 4 箱专用观察器，从侧推开始统计到最终撤离开始。

## 复算

在仓库根目录用带 NumPy 的 Python 运行。配对文件里的观测和 PhysX 真值按同一次运行的物理步配对。清单中的每个主表分组包含 A、第 4 箱和第 5 箱各一次试次，额外的 ArUco 重复试次在 JSON 中单列。 [数据清单](manifest.json) · [完整评分](scores.json)

```bash
e=scenes/w760_300mm_two_layer/experiments
python3 "$e/compare_vision_states.py" score \
  "$e/results/fitting_vs_aruco_20261126/manifest.json" /tmp/fr3-fitting-state-scores.json
```

新试次由 [采集入口](../../capture_fitting_states.py) 从对应断点启动。A 使用视觉拟合法基线保存的第一层两排实测断点，第 4 箱使用原 ArUco 在线验收断点。之前的拟合法日志没有三轴冲量，因此新采集的 A 段用来评分 S2 和 S3。第 5 箱使用基线验收的直推段。尝试在同一场景交替显示标记时，无标记帧仍检出了 ArUco，相关试次未用于评分。
