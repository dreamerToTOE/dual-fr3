# 创新点二独立测试集与闭环验证

## 实验口径

测试集按完整运行划分，不能把同一条运行的物理步拆到不同集合。开发集和验证集沿用历史归档，只用于冻结判据。测试集只使用 2026-11-22 新采集的完整运行。

状态指标按 PhysX 独立真值逐步统计。检测延迟按连续至少 3 个物理步的真值事件统计，从事件开始到第一次正确预测。置信区间使用运行级 bootstrap，5000 次重采样，95% 区间，随机种子 20261122。

总体识别成功率定义为有效真值步中预测状态等于真值的比例。UNKNOWN 仍计为识别错误。coverage 是有效真值步中输出不是 UNKNOWN 的比例。

## 数据划分

| 划分 | 运行数 | 内容 |
|---|---:|---|
| development | 3 | 历史归档 |
| validation | 3 | 历史归档 |
| test | 6 | A×3、U4×1、U5×2 新采集完整运行 |

完整测试运行包括 `fresh_a_01`、`fresh_a_02`、`fresh_a_03`、`fresh_u4_03_minus_040mm`、`fresh_u5_01_yaw_000` 和 `fresh_u5_02_yaw_035`。每条运行的命令、断点 SHA256、状态和停止原因记录在 `thesis_run_manifest.json`。

## 复算

[评分清单](thesis_test_manifest.json)引用同目录下的配对数据，包含观测、指令和独立 PhysX 真值。开发与验证的指令来自原始腕力日志，经原有 FK 脚本恢复。验证清单保留两次对同一第 5 箱运行的历史回放，共用一份输入。六次独立测试使用原始评分输入。

从仓库根目录用带 NumPy 的 Python 执行下列命令即可复算所有指标。

```bash
e=scenes/w760_300mm_two_layer/experiments
python3 "$e/thesis_metrics.py" "$e/results/thesis_test_manifest.json" /tmp/fr3-thesis-metrics.json \
  --legacy-seven-states
```

## S0 漏检分段复核

对同一批六次独立测试，以冻结的融合判据逐步回放。PhysX 在双侧吸盘均与箱体分离、侧吸约束解除、箱底仍受支撑时标 S0。空臂在此期间可以仍在运动。下表按物理步合并，主表的 68.4% 是六次运行的等权平均。

| 时段 | S0 真值步数 | 正确步数 | 漏检步数 | 召回率 |
|---|---:|---:|---:|---:|
| 最终释放前 | 23033 | 10209 | 12824 | 44.3% |
| 开杯或卸力至撤离开始 | 366 | 0 | 366 | 0.0% |
| 机械臂撤离箱面 | 4026 | 3179 | 847 | 79.0% |
| 空臂回停车位 | 18055 | 18004 | 51 | 99.7% |
| 已停靠后的确认 | 252 | 252 | 0 | 100.0% |

最终释放前占全部 S0 漏检的 91.0%。按相机时效、当前腕力、承托几何、工具分离证据的顺序统计第一个未满足的条件。该时段有 6314 步的工具分离证据不足，5698 步未通过视觉承托几何判据，810 步的视觉帧缺失或过期，2 步的当前腕力超过低腕力阈值。三次 A 段在最终释放前共有 5658 步未通过料台附近的视觉承托几何判据。在这组样本中，三次运行的视觉箱心高度中位偏差均约 −45 mm。

开杯或卸力至撤离箱面的合并召回率为 72.4%。其中三次 A 段的双臂撤离动作命中 2719/3126 步（87.0%），首次正确报告 S0 比实际分离晚 1.61–1.67 s。回放中，刚离箱的漏检发生在分离证据不足时。估计器允许以超过 25 mm 的几何离箱距离确认分离，也允许在沿吸盘法向估计间隙至少 5 mm、连续 50 ms 低腕力时提前确认。

分段使用配对文件中的 `phase_times_for_scoring_only`。A 段依次以 `upper_release`、`A_withdraw_laterally` 开始、`A_withdraw_up` 完成和 `upper_A_capture` 为分界。第 4、5 箱依次以 `upper_B_front_unload`、`upper_B_front_withdraw`、最后一次 `upper_B_park`、`upper_B_release / TOOLS_PARKED` 和 `upper_slot_complete` 为分界。每段取上个标记之后至下个标记当步。阶段标记仅用于事后汇总。

## 闭环融合仿真

闭环运行使用 U5 0° 起始断点和融合观测线。监督器共记录 13056 个决策，其中保持 9392 步，继续 3664 步，保持比例 71.9%。

运行最终在 `upper_B_rear_travel` 因左腕 9.0174 N、0.29697 N·m 超出包络而停止。它证明了观测结果已经进入控制闭环，也暴露出当前受力异常不能靠保持动作自动消除。该运行不计入三种观测线的完整成功率。

## 当前结论

融合线在独立完整测试集上的总体识别成功率为 76.8% ，95% 置信区间为 [62.6%, 84.7%]。S0 到 S5 已有独立真值事件。S6 在 U4 完整运行中出现，但三条观测线都没有产生有效的 S6 正预测，因此 S6 精确率和 F1 没有可定义的正预测样本，S6 召回率为 0。

这轮结果可以作为大论文的初版独立测试结果，S6 和闭环保护停机仍应作为后续专项实验，不能把当前结果表述成所有状态都已达到最终工程指标。
