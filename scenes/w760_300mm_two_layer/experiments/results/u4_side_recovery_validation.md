# 上层第 4 箱持续失载后的回载验证

在单个 Isaac Sim 4.5.0 实例中，从 `U4_minus040_repeat/upper_landing_checkpoint.json` 恢复上层第 4 箱。断点已经完成跨接缝搬运。将箱子推至后墙并确认承载后，沿 X 轴向远离侧邻箱的方向平移 6 mm，左臂的撤离目标为 4 mm。沿用此前的 60 步侧向观测屏蔽来建立失载。随后解除屏蔽，等待 90 步，再将箱体移回其原 X 坐标朝侧邻箱多 0.15 mm 的位置，采集后续 120 步。两次位姿扰动仅修改 X 坐标，右臂保持原命令。

| 事件 | 控制步 | 证据 |
| --- | ---: | --- |
| 扰动前 S6 | 15476 | PhysX 确认侧邻箱和后墙同时承载 |
| 确认失载，进入 S5 | 15511 | `side_load_lost_silent`，只保留后墙承载 |
| 无屏蔽、侧向无载 | 15537–15626 | 90/90 步判为 S5，回载事件和 S6 误报各 0 次 |
| PhysX 首次恢复侧载 | 15627 | 第 4 箱与侧邻箱 `Cube_8` 重新传递 X 向载荷，后墙仍承载 |
| 观测器确认回载，切换到 S6 | 15629 | `side_load_recovered`，此后连续 118 步为 S6，直至记录结束 |

PhysX 真值以两组指定接触对的当步主轴法向冲量为准，阈值为 `1e-5 N·s`。后墙在扰动后的 270 步都有载。侧载从第 15627 步开始持续到结束，第三个承载样本与观测器确认同在第 15629 步。以首个承载样本计时，**S5→S6 延迟为 2 个采样间隔，即 16.7 ms（120 Hz）**。

沿用原回载判据。在视觉确认箱体仍位于可发生侧接触的范围内、右臂仍压住箱体、且后墙承载已确认的条件下，右腕 `Fx < −0.15 N`，或 `Mz < −0.055 N·m` 且 `Fx < 0.35 N`，构成正向侧载证据。这次三个连续正样本的 `Fx` 依次为 −1.64、−0.52、−0.31 N，第三步才确认回载。评分同时核对 S6 的两个具体边界。

恢复前的无屏蔽观察窗没有误报。另有 17 个 S6 样本出现在初始的 60 步屏蔽失载段，那里 PhysX 已无侧载，尚处于失载建立过程，且没有回载事件。这一结果来自一次受控仿真。回载后 PhysX 侧向力为 1.55–7.45 N，中位数 2.88 N，尚未覆盖 0.1–1 N 的弱回载。实验专用腕力监视上限沿用 30 N、2 N·m，本次右腕峰值为 13.67 N、0.516 N·m，出现在初次移开箱体的第一步。采样结束后运行器按实验入口设置停止。

从该断点复现的入口是 `two_row_physx.py --u4-side-recovery-probe`。逐步证据、统计结果及原始日志的 SHA-256 见同目录下的 [JSON 结果](u4_side_recovery_validation.json)。本次输入断点的 SHA-256 为 `2b54b81c0f0f8181d0565756dad49844197bc0da9dac8de6ffb8125678f793f4`。
