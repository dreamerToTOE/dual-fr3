# 上层第 4 箱弱回载独立试验

本轮从同一个上层第 4 箱断点独立重启了 5 次，目标侧载为 0.35 N。每次都先完成后墙确认，再让侧载消失，解除观测屏蔽，最后尝试恢复侧载。PhysX 只使用 `Cube_10–Cube_8` 的当步 X 向法向冲量判断侧载，后墙必须同时保持 loaded。弱回载的合格窗口定义为连续至少 3 个采样步、每步 0.1–1.0 N。

| 试次 | 结果 | 弱力区间采样 | 最长连续弱力 | 误报 S6 |
| --- | --- | ---: | ---: | ---: |
| 035-rerun | 接触冲量振荡 | 61 | 4 | 0 |
| 035-rerun2 | 未接触侧邻箱 | 0 | 0 | 0 |
| 035-rerun3 | 未接触侧邻箱 | 0 | 0 | 0 |
| 035-rerun4 | 单步弱力后转强接触 | 1 | 1 | 0 |
| 035-force | 只形成强接触 | 0 | 0 | 0 |

五次均没有形成合格的独立弱回载正例。第一种位置调节试次出现过 0.1–1 N 样本，但冲量在零和大于 1 N 之间跳变。第 4 次有一个 0.677 N 样本，随后进入约 1.1–7 N 的强接触。最后一次给侧邻箱施加 0.35 N 外力后，PhysX 侧载仍为 1.45–7.01 N，说明当前箱体、墙面和接触求解器会把弱输入放大为强碰撞响应。

恢复前的无屏蔽观察窗口共 5 次均没有回载事件和 S6 误报。后墙在这些窗口中保持承载，误报结果可用，弱回载召回率暂时不能计算。当前结果说明场景接触刚度和求解器离散性阻止了可重复的 0.1–1 N 侧载，而不是证明判据已经通过弱回载测试。

结果 JSON 保留每次运行的逐步真值和观测器流。当前代码和记录仍在创新点二分支。下一步需要使用更柔顺的接触几何、接触材料参数或经过标定的合规侧向执行器，先构造稳定弱载，再测试识别延迟与漏报。
