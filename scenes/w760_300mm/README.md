# 76 cm 托盘、30 cm 高墙、第一层五箱基线

这是后续实验使用的场景。四面墙高 **300 mm**，托盘内宽 **760 mm**，箱体边长 **150 mm**。原 76 cm 场景的墙高为 150 mm。84 cm 场景同时保留了 150 mm 墙高和更宽的插入槽。双臂滑轨沿 Y 轴，中心位于 X = ±600 mm。后置 D455 仿真相机 Z = 2.45 m，RGB 为 1280 × 960。控制和 PhysX 均为 120 Hz，界面按 30 Hz 刷新。

五箱共用上料点 `[0, −300, 787]` mm，保留各自的 landing。全程从竖直面吸附，箱体保持直立。以下坐标为 A 阶段规划目标，以托盘中心线为 X = 0，+Y 指向后墙。

| 箱号 | Landing X / Y / Z（mm） | A 阶段吸附面 | 就位动作 |
| --- | --- | --- | --- |
| 1 | 0 / 736 / 787 | 左右面 | 靠左墙 |
| 2 | +45 / 736 / 787 | 前后面 | 靠右墙 |
| 3 | −29.15 / 736 / 787 | 左右面 | 靠第 1 箱 |
| 4 | +106.00 / 734.77 / 787 | 前后面 | 先贴第 2 箱，左臂撤出后再贴后墙 |
| 5 | +1.69 / 735.06 / 787 | 左右面 | 用相机对准第 3、4 箱间的实际槽位，沿 +Y 直推 |

第 2、4 箱由左臂吸后面，右臂吸前面。A 阶段导引路点用于在线 IK 调整和避障检查，运行时不回放 A/B1/B2 轨迹缓存。控制使用 RGB、关节编码器和腕部六维力，PhysX 箱位用于复核。已码箱体仍作为动态障碍参与检查。

## 运行

在仓库根目录使用 Isaac Sim 4.5.0 的 Python。 `ISAAC_SIM_DIR` 指向安装目录，官方 FR3 USD 必须能通过 Isaac Sim 资产源解析。以下命令均启动一个 Isaac Sim 实例。演示时选择其中一条。

```bash
# 可视化自动从第 1 箱上料开始
"$ISAAC_SIM_DIR/python.sh" scenes/w760_300mm/continuous_side_row.py /tmp/fr3-w760-h300

# 从实测第 3 箱落地、双臂向上撤离后的断点开始
"$ISAAC_SIM_DIR/python.sh" scenes/w760_300mm/continuous_side_row.py /tmp/fr3-w760-h300-cube3 --resume-cube3
```

默认用 3 个 CPU 进程做碰撞检查，可用 `--collision-workers 1` 改为串行检查。输出包括运行报告、传感器日志和关键阶段的 Isaac Sim 视口截图。可用系统 Python 运行 `--check-only` 检查场景装配，或审计已完成的运行。

```bash
python3 scenes/w760_300mm/continuous_side_row.py /tmp/fr3-w760-h300 --check-only
python3 scenes/w760_300mm/continuous_side_audit.py /tmp/fr3-w760-h300
```

## 验收范围

五箱已在 Isaac Sim 可视化模式中通过断点接力就位，RGB 和 PhysX 均确认最终顺序为 **1、3、5、4、2**。最后一段从第 3 箱实测落地断点继续，第 4、5 箱在该段分别完成从上料到就位，记录到零次非预期机械臂接触。第 4 箱 B2 右臂的支撑力有 99.79% 的采样落在 `(0.1, 6] N`，最长低于或等于 0.1 N 的时段为 8.3 ms。第 5 箱沿 +Y 直推约 341 mm，最终两侧缝隙合计约 8.47 mm。整排从第 1 箱上料起的无中断验证和实体 FR3 验证仍待完成。 [验收摘要](validation/acceptance_summary.json)
